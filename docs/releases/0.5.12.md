Sagax 0.5.12 est une version de correctifs et de sécurité. Sur iPhone, un fil s'ouvre toujours, ou dit pourquoi. Les clés de sécurité couvrent plus d'actions, les lectures sensibles et les noms d'outils sont mieux gardés, et les organisations gagnent un effacement des données plus complet et un contrôle plus strict des moteurs et des niveaux d'approbation.

## iPhone et iPad

* **Un fil s'ouvre toujours** : sur un bot partagé d'une organisation, toucher un fil pouvait ramener à l'accueil sans rien dire. Le fil choisi s'ouvre maintenant, un fil disparu ouvre le fil courant du bot, et Sagax redemande la liste au serveur avant de conclure à un problème.
* **Un message clair** : quand un fil ne peut vraiment pas s'ouvrir, l'écran l'explique, avec **Réessayer** et **Retour aux bots**.

## Fils et organisations

* **Fil choisi toujours présent** : sur un serveur d'organisation, le fil ouvert pour une personne fait toujours partie de ses fils, sur le bureau, le web et les mobiles. Jamais le fil de quelqu'un d'autre.
* **Liste de moteurs vide = aucun moteur** : quand un admin retire tous les fournisseurs d'une organisation dans Perspicax, aucun moteur n'est permis (avant, une liste vide les ouvrait tous). Le sélecteur de modèle, sur le bureau comme sur iPhone, marque chaque fournisseur non permis, un changement de modèle est refusé et Auto ne choisit aucun moteur.

## Sécurité

* **Clés de sécurité sur plus d'actions** : l'écriture d'un fichier, le contrôle de l'écran (`computer_use`, la VM locale) et l'envoi d'un formulaire par le navigateur entrent maintenant dans les classes de risque. Une personne qui protège « destructif », « irréversible » ou « envoi externe » par une clé de sécurité la verra demandée pour ces actions. Une simple lecture d'écran ou une page ouverte en lecture n'en demande pas.
* **Noms d'outils réservés** : un serveur MCP ne peut plus porter un nom qui imite un outil intégré de Sagax (`mcp`, un nom avec `__`, ou les familles `sagax`, `perspicax`, `claude_ai`). Un outil n'est reconnu comme intégré que si aucun autre serveur du tour ne peut produire ce nom.
* **Lectures sensibles dans l'environnement** : un chemin est d'abord résolu dans l'environnement isolé (liens symboliques, `/proc`) avant d'être lu. Les secrets de `/proc` et un lien vers des identifiants (`.ssh`, `.git-credentials`, `.aws`...) sont refusés, peu importe qui demande.

## Données personnelles (Loi 25)

* **Effacement complet** : quand une personne efface son compte, sa base Data personnelle sur chaque bot et celle de ses fils confidentiels sont effacées avec lui.
* **Exports dans la portée de la personne** : sur un bot partagé, un export de la base d'une personne va dans son fil ou dans son propre dossier, jamais dans l'espace commun du bot.
* **Niveau Auto des membres** : quand l'organisation désactive les niveaux automatiques pour les bots des membres, aucune voie (console d'admin, passation, copie, import, transfert, nouveau bot) n'enregistre plus Auto sur le bot ou le fil d'un membre.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.12-arm64.dmg` ou `Sagax-0.5.12-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.12-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.12-win-x64.zip` et `Sagax-0.5.12-win-arm64.zip`.

## English

Sagax 0.5.12 is a fixes and security release. On iPhone, a thread always opens, or says why. Security keys cover more actions, sensitive reads and tool names are better guarded, and organizations get more complete data erasure and stricter control of engines and approval levels.

* **iPhone and iPad: a thread always opens**: on an organization's shared bot, tapping a thread could return to the home screen silently. The selected thread now opens, a removed thread opens the bot's current thread, and Sagax asks the server again before concluding there is a problem. When a thread really cannot open, the screen explains why, with **Retry** and **Back to bots**.
* **Selected thread always listed**: on an organization server, the thread opened for a person is always part of their threads, on desktop, web and mobile. Never someone else's thread.
* **Empty engine list means no engine**: when an admin removes every provider of an organization in Perspicax, no engine is allowed (an empty list used to allow them all). The model picker, on desktop and iPhone, marks each provider as not allowed, a model change is refused and Auto picks no engine.
* **Security keys on more actions**: writing a file, screen control (`computer_use`, the local VM) and submitting a form through the browser now belong to risk classes. A person who protects "destructive", "irreversible" or "external send" with a security key will be asked for it on these actions. A plain screenshot or a page opened for reading does not ask.
* **Reserved tool names**: an MCP server can no longer use a name that imitates a Sagax built-in tool (`mcp`, a name with `__`, or the `sagax`, `perspicax`, `claude_ai` families). A tool counts as built-in only when no other server of the turn can produce that name.
* **Sensitive reads in the environment**: a path is first resolved inside the isolated environment (symbolic links, `/proc`) before it is read. `/proc` secrets and a link to credentials (`.ssh`, `.git-credentials`, `.aws`...) are refused, whoever asks.
* **Personal data (Québec Law 25)**: when a person erases their account, their personal Data database on every bot and the ones of their confidential threads are erased with it. On a shared bot, an export of a person's database goes to their thread or their own folder, never to the bot's shared space. When the organization turns off automatic levels for members' bots, no path (admin console, handoff, copy, import, transfer, new bot) saves Auto on a member's bot or thread anymore.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
