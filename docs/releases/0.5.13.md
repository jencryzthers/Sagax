Sagax 0.5.13 rend les appels vocaux plus naturels et plus sûrs, et corrige les environnements isolés sur Kubernetes : écriture de fichiers, saisie au clavier, captures du navigateur et connexion GitHub y fonctionnent de nouveau.

## Appels vocaux

* **Réponses faites pour l'oreille** : le bot donne d'abord le verdict, en quelques phrases courtes, sans tableaux, sans chemins ni markdown. Les heures et les nombres sont dits naturellement, dans la langue de votre dernier message, et le bot pose une seule question à la fois, seulement quand une vraie décision vous revient.
* **Jamais d'identifiants lus à voix haute** : les UUID, les empreintes, les jetons, les numéros comme `#1234` et les longs chemins sont retirés de ce qui est dit, sur le bureau, sur le serveur et sur iPhone. En voix continue, un identifiant coupé entre deux morceaux est retenu jusqu'à ce qu'il soit complet, puis retiré.
* **Approbations à deux options** : une action à approuver est demandée ainsi : « Autoriser une fois, ou refuser ? ». Un oui clair autorise une fois, un non clair refuse ; une hésitation, une condition, une question ou une réponse mêlée fait reposer la question. « Toujours autoriser » n'est jamais accessible par la voix, et une action protégée par une clé de sécurité ne peut pas être approuvée par la voix.
* **Même règle partout** : l'appel GPT-Live et l'ancien appel macOS (dictée) suivent la même règle d'approbation. L'ancien appel macOS marque aussi ses tours comme un appel vocal : le bot peut raccrocher à la fin, après son au revoir.
* **Un échec, une phrase** : quand une étape échoue pendant un appel, le bot le dit en une phrase avec quoi faire, puis se tait.

## Environnements isolés

* **Kubernetes** : les variables des commandes passent maintenant par l'entrée standard, jamais par la ligne de commande. `write_file`, la saisie de texte et l'ouverture d'une adresse par `computer_use`, la capture d'une page par `browse`, la connexion GitHub, les mots de passe du bureau à distance, la copie des pièces jointes et les variables des serveurs MCP d'une personne fonctionnent de nouveau dans un environnement sur Kubernetes.
* **Gros fichiers** : `write_file` écrit maintenant des fichiers de plus d'environ 96 Kio, jusqu'à la limite annoncée de 1 Mio, aussi sur Docker. Si le contenu n'arrive pas en entier, l'écriture est refusée et le fichier cible reste intact.
* **Écriture par lien refusée** : comme la lecture, l'écriture résout d'abord le chemin dans l'environnement. Un lien qui mène vers des identifiants (`.ssh`, `.git-credentials`, `.aws`...), vers un fichier caché ou vers un secret de `/proc` est refusé.

**Pour l'opérateur d'un serveur** : le correctif Kubernetes est dans le provisionneur des environnements. Mettez à jour le provisionneur Kubernetes avant le serveur. Un serveur à jour avec un ancien provisionneur écrit les fichiers de 64 Kio et moins comme avant ; au-delà, l'écriture est refusée clairement, sans toucher la cible.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.13-arm64.dmg` ou `Sagax-0.5.13-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.13-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.13-win-x64.zip` et `Sagax-0.5.13-win-arm64.zip`.

## English

Sagax 0.5.13 makes voice calls more natural and safer, and fixes isolated environments on Kubernetes: writing files, typing, browser captures and the GitHub connection work there again.

* **Answers made for listening**: the bot gives the verdict first, in a few short sentences, with no tables, paths or markdown. Times and numbers are said naturally, in the language of your last message, and the bot asks one question at a time, only when a real decision is yours.
* **Identifiers never read aloud**: UUIDs, hashes, tokens, numbers such as `#1234` and long paths are removed from speech, on desktop, on the server and on iPhone. In streamed speech, an identifier split across two chunks is held until complete, then removed.
* **Two-option approvals**: an action to approve is asked as "Allow once, or deny?". A clear yes allows once, a clear no denies; hesitation, a condition, a question or a mixed answer asks again. "Always allow" is never reachable by voice, and an action protected by a security key cannot be approved by voice.
* **Same rule everywhere**: the GPT-Live call and the older macOS call (dictation) use the same approval rule. The older macOS call also marks its turns as a voice call, so the bot can hang up at the end, after its goodbye.
* **One failure, one sentence**: when a step fails during a call, the bot says so in one sentence with what to do, then stays quiet.
* **Kubernetes environments**: command variables now go through standard input, never the command line. `write_file`, typing text and opening an address with `computer_use`, page capture with `browse`, the GitHub connection, remote desktop passwords, attachment copy and a person's MCP server variables work again in an environment on Kubernetes.
* **Larger files**: `write_file` now writes files over about 96 KiB, up to the advertised 1 MiB limit, on Docker too. If the content does not arrive in full, the write is refused and the target file is left untouched.
* **Writing through a link refused**: like reading, writing first resolves the path inside the environment. A link leading to credentials (`.ssh`, `.git-credentials`, `.aws`...), to a hidden file or to a `/proc` secret is refused.
* **For a server operator**: the Kubernetes fix lives in the environment provisioner. Update the Kubernetes provisioner before the server. An updated server with an older provisioner writes files of 64 KiB or less as before; above that, the write is refused clearly, without touching the target.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
